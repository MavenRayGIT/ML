# ML

Mack & Lee repository. Application code, design library references, and **agent-site** (Track A) docs and apps live under [`ml/`](ml/).

| Path | Contents |
|------|----------|
| `ml/agentsites/` | Track A documentation, handoffs, per-client folders (e.g. Astro apps) |
| `ml/library/` | Module library notes and registry |
| `ml/templates/` | Project templates |

Cloudflare Pages build roots should point at the specific app under `ml/agentsites/<client>/`, not at the whole repo.
