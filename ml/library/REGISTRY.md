## Promotion checklist

A module can graduate to this registry when:

- It has been used in 2+ contexts (multiple pages within a project, or across projects).
- It has been validated visually + structurally — auto-layout works at edge sizes, variants are clean, no project-specific content baked in.
- A `MODULES/<name>.md` spec has been written.
- It has been copied to the M&L Library Figma file.
- The originating project file has replaced its local instance with a library instance.
